# Movie Rating System

A Java program that accepts five movie names and ratings, calculates the average rating, classifies the user’s movie taste, checks for extreme ratings, evaluates consistency, prompts for a favorite genre, and provides a movie recommendation.

## Reflection

* **Nested `if` vs. `if-else`:** A nested `if` only runs its inner condition when the outer condition evaluates to true, whereas an `if-else` structure immediately chooses between mutually exclusive paths.
* **`switch` Statements:** A `switch` statement is cleaner and easier to read than multiple `if-else` checks when evaluating a single variable against discrete values.
* **Conditional (Ternary) Operator:** The conditional operator (`? :`) allows for quick, concise decisions in a single line of code.
* **Short-Circuit Evaluation:** Short-circuit evaluation stops evaluating logical expressions as soon as the overall result is determined (e.g., using `&&` or `||`), making code both faster and safer against runtime errors.
