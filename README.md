Movie Rating System
A Java program that asks for five movie names and ratings, calculates the average, classifies the user’s movie taste, checks for extreme ratings, evaluates consistency, asks for a favorite genre, and gives a movie recommendation.

Reflection
A nested if only runs its inner condition when the outer one is true, while an if‑else chooses between different paths immediately. A switch statement is cleaner and easier to read than multiple if‑else checks for one variable. The conditional operator makes quick decisions in a single line. Short‑circuit evaluation stops checking conditions as soon as the result is known, making logical expressions faster and safer.
